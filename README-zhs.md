# Store Fix

[English](README.md) | [简体中文](README-zhs.md) | [繁體中文](README-zht.md)

Store Fix 是一个用于修正 App Store 链接地区的浏览器扩展。它会在你点击链接或直接访问时重写 `apps.apple.com` 地址，让 App Store 页面保持在你选择的国家或地区。

Store Fix 支持通过 App Store 安装 Safari 版本，也支持通过 Chrome 网上应用店或本仓库手动安装 Chrome 扩展。
