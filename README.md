# Store Fix

[English](README.md) | [简体中文](README-zhs.md) | [繁體中文](README-zht.md)

Store Fix is a browser extension that keeps App Store links on the storefront region you choose. It rewrites `apps.apple.com` URLs when you click links or navigate directly, helping App Store pages open in the correct country or region.

Store Fix supports Safari through the App Store app and Chrome through the Chrome Web Store or manual installation from this repository.
